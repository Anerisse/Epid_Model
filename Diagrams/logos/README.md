# Логотипы и иконки SIMULA

Абстрактные варианты, без отсылки к буквенным обозначениям S/I/R.

## Файлы

| Файл | Назначение |
|---|---|
| `simula-icon-abstract.svg` | Основной знак — две дуги (цикл/динамика) вокруг узла. Квадрат 512×512. |
| `simula-icon-orbit.svg` | Абстрактные орбиты — сеть связей/взаимодействий. |
| `simula-icon-grid.svg` | Сеть узлов и связей — топология/граф модели. |
| `simula-icon-wave.svg` | Две синусоподобные волны — динамика/изменение во времени. |
| `simula-icon-mono.svg` | Монохромный вариант `simula-icon-abstract.svg`. |
| `simula-favicon.svg` | Фавиконка 64×64. |
| `simula-logo-horizontal.svg` | Горизонтальный логотип (знак + SIMULA + подзаголовок). |
| `simula-logo-vertical.svg` | Вертикальный логотип. |
